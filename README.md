# 🔥 D2R Navigator (D2R-HUD) — 디아블로 2 레저렉션 공략 HUD

> 게임 화면 위에 투명하게 떠 있는 실시간 공략 도우미입니다.  
> 게임을 끄지 않고 퀘스트 동선, 룬워드, 큐빙 공식을 바로 확인하세요.

---

## 📢 최신 버전: v1.1.3 (2026.02.23)
이번 업데이트에서는 **수동 다운로드 방식**을 도입하여 윈도우 보안 문제와 자동 설치 오류를 근본적으로 해결했습니다. 또한 **멀티 모니터** 환경에서의 창 관리 성능이 대폭 향상되었습니다.

---

## 📦 설치 및 업데이트 방법

### 1. 신규 설치
- GitHub의 [Releases](https://github.com/yobi7979/D2R-HUD/releases) 페이지에서 가장 최근의 `D2R-HUD-v1.1.3-win32-x64.zip` 파일을 다운로드합니다.
- 원하는 폴더에 압축을 풉니다.
- `D2R-HUD.exe`를 실행합니다.

### 2. 업데이트 방법 (v1.1.3 이상)
1. HUD의 **⚙️ 설정 아이콘**을 클릭합니다.
2. 하단의 **[업데이트 확인]** 클릭 후 **[다운로드 시작]** 버튼을 누릅니다.
3. 파일 저장 창이 뜨면 원하는 곳에 `.zip` 파일을 저장합니다.
4. 다운로드가 완료되면 해당 압축 파일을 풀어, **현재 HUD가 설치된 폴더의 파일들을 덮어쓰기** 합니다.

> ⚠️ **보안 안내**: 실행 시 Windows Defender 스마트스크린 경고가 뜰 수 있습니다.  
> **"추가 정보" → "실행"** 을 클릭하면 정상적으로 실행됩니다.

## 🖥️ 화면 구성 및 조작

- **패널 이동**: 모든 UI 창(메인 HUD, 공략 사전, 설정창)의 **상단 제목 바를 드래그**하여 원하는 위치로 배치할 수 있습니다.
- **클릭 투과**: HUD 창이 게임 화면을 가리고 있어도, 버튼이 없는 투명한 영역은 **클릭이 게임으로 그대로 전달**되어 플레이를 방해하지 않습니다.

## 🎮 주요 기능

### 1. 실시간 퀘스트 HUD
- 난이도별 퀘스트 동선과 필수 체크 항목을 표시합니다.
- 항목 클릭 시 체크/해제 가능하며, 모든 진행 상태는 자동으로 저장됩니다.
- 가이드 상단 좌우 버튼으로 단계를 넘길 수 있습니다.

### 2. 룬워드 / 큐빙 사전 (🗂️ 아이콘)
- **룬워드**: 전체 룬워드의 재료, 필요 레벨, 변동 옵션을 검색/확인합니다.
- **큐빙 공식**: 아이템 업그레이드, 룬 합성 등의 공식을 바로 확인합니다.

### 3. 멀티 모니터 완벽 지원
- 주 모니터뿐만 아니라 보조 모니터에서도 HUD를 자유롭게 배치하고 저장할 수 있습니다.
- 모니터 해상도나 배율이 달라도 UI 스케일링이 정상적으로 적용됩니다.

### 4. 자동 숨김 (Auto-hide)
- 디아블로 2 게임 화면이 활성화되어 있을 때만 HUD가 보이도록 설정할 수 있습니다.
- **캘리브레이션**: 특정 좌표의 픽셀 색상을 감지하여 게임 활성화 여부를 정확히 판단합니다.

## ⌨️ 단축키 안내

| 단축키 | 기능 설명 |
|--------|------|
| `Ctrl + Q` | **HUD 전체 표시 / 숨기기** (설정에서 변경 가능) |
| `Ctrl + F8` | **모니터 간 전환** (보조 모니터로 HUD 즉시 이동) |
| `Ctrl + F9` | HUD 위치를 **왼쪽 상단**으로 고정 |
| `Ctrl + F10` | HUD 위치를 **오른쪽 상단**으로 고정 |
| `Ctrl + F11` | HUD 위치를 **왼쪽 하단**으로 고정 |
| `Ctrl + F12` | HUD 위치를 **오른쪽 하단**으로 고정 |
| `Ctrl + →` | 공략 가이드 **다음 단계**로 이동 |
| `Ctrl + ←` | 공략 가이드 **이전 단계**로 이동 |

## ❓ 자주 묻는 질문 (FAQ)

**Q. HUD가 화면 밖으로 사라졌어요.**  
A. 프로그램을 재시작하면 주 모니터 중앙 위치로 초기화되어 나타납니다.

**Q. 인터넷 연결이 꼭 필요한가요?**  
A. 네. 최신 공략 가이드와 UI를 온라인(Cloudflare Pages)에서 실시간으로 불러와 항상 최신 정보를 제공합니다.

**Q. 업데이트 버튼을 눌러도 반응이 없어요.**  
A. 설정창을 닫았다가 다시 열어보세요. v1.1.3에서는 진입 시 UI 상태를 자동으로 초기화합니다.
