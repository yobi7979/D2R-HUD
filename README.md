# 🔥 D2R Navigator — 디아블로 2 레저렉션 공략 HUD

> 게임 화면 위에 투명하게 떠 있는 실시간 공략 도우미입니다.  
> 게임을 끄지 않고 퀘스트 동선, 룬워드, 큐빙 공식을 바로 확인하세요.

---

## 📦 설치 방법

1. 배포받은 `D2R-HUD Setup x.x.x.exe` 파일을 실행합니다.
2. 설치가 완료되면 바탕화면 또는 시작 메뉴에서 **D2R-HUD** 를 실행합니다.
3. 인터넷 연결이 필요합니다 (최신 공략 데이터를 온라인에서 불러옵니다).

> ⚠️ Windows Defender 스마트스크린 경고가 뜰 수 있습니다.  
> **"추가 정보" → "실행"** 을 클릭하면 정상적으로 실행됩니다.

---

## 🖥️ 기본 화면 구성

실행하면 화면 중앙에 작은 HUD 패널이 나타납니다.

```
┌─────────────────────────── [📖] [🗂️] [⚙️] [✕]
│  퀘스트 가이드 제목               단계
│  현재 위치                         1
├──────────────────────────────────────────────
│  ◀ 이전                          다음 ▶
├──────────────────────────────────────────────
│  ➤ 이동 경로
│
│  □ 할일 1
│  □ 할일 2
│  ✓ 완료된 항목 (클릭으로 체크)
│
│  💡 노트 및 전략 팁
└──────────────────────────────────────────────
```

---

## 🎮 주요 기능

### 1. HUD (퀘스트 가이드)
- 현재 퀘스트 단계, 이동 경로, 할 일 목록을 실시간으로 표시합니다.
- **할 일 항목을 클릭**하면 체크/해제할 수 있습니다.
- **이전 / 다음 버튼** 또는 단축키로 단계를 이동합니다.
- HUD 창의 **제목 바를 드래그**하면 원하는 위치로 이동할 수 있습니다.

### 2. 가이드 선택 (📖 아이콘)
HUD 우측 상단 **📖 아이콘**을 클릭하면 가이드 관리 패널이 열립니다.

| 가이드 | 설명 |
|--------|------|
| 퀘스트 타임라인 | 노말~헬 전 난이도 메인 퀘스트 동선 |
| 어비스 워록 (레벨링) | 메아리 치는 타격 워록 완전 육성 가이드 |
| 워록 화염 (레벨링) | 화염 계열 워록 레벨링 가이드 |

### 3. 룬워드 / 큐빙 사전 (🗂️ 아이콘)
HUD 우측 상단 **🗂️ 아이콘**을 클릭하면 기타 패널이 열립니다.

- **룬워드 탭**: 전체 룬워드 목록, 재료 룬, 효과 확인
- **큐빙 탭**: 호라드림의 함 조합 공식 전체 목록
- **검색창**: 룬 이름, 아이템 타입, 키워드로 즉시 검색 가능

### 4. 설정 (⚙️ 아이콘)
- **토글 단축키 설정**: HUD를 보이게/숨기게 하는 단축키를 원하는 키로 변경 (기본값: `Ctrl+Q`)
- **자동 숨김 (Auto-hide)**: 디아블로 2가 활성화 창일 때만 HUD를 표시하도록 설정
  - **캘리브레이션**: 숨김 기준 픽셀 위치를 설정합니다

## ⌨️ 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+Q` | HUD 표시 / 숨기기 (설정에서 변경 가능) |
| 가이드 패널에서 ▶ 클릭 | 다음 단계로 이동 |
| 가이드 패널에서 ◀ 클릭 | 이전 단계로 이동 |

---

## 💡 사용 팁

- HUD는 게임 위에 투명하게 떠 있어 게임 플레이를 방해하지 않습니다.
- HUD가 겹치는 부분은 **클릭이 게임으로 그대로 전달**됩니다.
- 가이드 내 체크리스트는 자동으로 저장됩니다.
- 게임 재시작 후에도 마지막으로 보던 단계가 유지됩니다.
- **UI 상단 제목 바를 드래그**하여 모든 패널의 위치를 자유롭게 조정하세요.

## ❓ 자주 묻는 질문

**Q. HUD가 안 보여요.**  
A. 트레이 아이콘을 우클릭하거나 `Ctrl+Q`를 눌러 보세요.

**Q. 흰 화면이 뜨고 내용이 안 나와요.**  
A. 인터넷 연결을 확인해 주세요. 최신 데이터를 온라인에서 불러옵니다.

**Q. 설치 시 바이러스 경고가 떠요.**  
A. Electron 기반 앱의 특성상 간혹 오탐이 발생합니다. "추가 정보 → 실행"을 클릭하세요.
